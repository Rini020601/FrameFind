Features

Built natively for macOS workflows

No cloud uploads, no external OCR binaries, no sluggish Electron wrappers. Powered by PyObjC, Apple Vision, SQLite FTS5, and PySide6.

🏷️

Context-Aware Auto-Renaming

Combines frontmost macOS app detection, active Chrome tab parsing, YouTube watch-title filtering, and cross-frame salience to name both screenshots and recordings cleanly.

⏱

Jump-to-Timestamp & OCR Overlay

SQLite FTS5 (WAL + BM25) searches Apple Vision OCR and optional local mlx-whisper transcripts, seeking the player to the exact second with yellow bounding-box highlights and 1-click Copy Text/Code.

🔎

Native Finder & Spotlight Search

Writes deduplicated frame words into macOS Finder comments (kMDItemFinderComment + mdimport), so typing any word from inside a video or screenshot in Finder finds it immediately.

🔒

1-Click Privacy Redactor

Automatically detects OpenAI/Gemini API keys (sk-, AIza), GitHub tokens (ghp_), AWS keys (AKIA), Bearer tokens, Private Keys, passwords, and emails — blurring exact bounding boxes before export.

🗜

VideoToolbox Hardware Compression

Compresses bloated macOS .mov captures via hardware-accelerated h264_videotoolbox (with libx264 and OpenCV fallbacks), saving 80–90% disk space while keeping text sharp.

📂

Menu Bar Tray & Background Daemon

Includes a lightweight macOS menu bar icon (Quick Search, Pause/Resume Auto-Rename, Recent Captures in Finder, Orphan Cleanup) plus a silent LaunchAgent watching Desktop, Movies, Downloads, and Documents.

Pipeline

How FrameFind works under the hood

01

Watch & Sample Keyframes

watchdog debounces new captures until macOS finishes writing, then extracts keyframes on scene transitions (window/slide switches) and 2-second intervals.

02

Vision OCR, Whisper & Rename

Apple Vision (VNRecognizeTextRequest) extracts text and bounding boxes on the Neural Engine, optional Whisper aligns spoken words, and SmartNamer renames the file and updates Spotlight.

03

Search, Redact & Compress

Filter by Videos, Screenshots, Code, Slides, or Meetings in the PySide6 desktop app or CLI. Jump to highlighted matches, blur secrets in 1 click, or shrink multi-GB clips.

Quickstart

Up and running in 60 seconds

Requires macOS (Apple Silicon or Intel) and Python 3.10+.

git clone https://github.com/Rini020601/FrameFind.git
cd FrameFind
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Optional: VideoToolbox compression & local Whisper speech search
brew install ffmpeg
pip install mlx-whisper
# Launch the native PySide6 desktop app + menu bar tray
python main.py

# Or use the CLI directly
python main.py index ~/Desktop
python main.py search "TypeError"
python main.py rename "Screen Recording.mov"
python main.py stats
python main.py cleanup
# Install as a silent macOS LaunchAgent (auto-starts on login)
python daemon.py install

# Check service status
python daemon.py status

# Uninstall anytime
python daemon.py uninstall
