Features

Built natively for macOS workflows

No cloud uploads, no external OCR binaries, no sluggish Electron wrappers. Everything runs privately on your Mac.

⏱

Jump-to-Timestamp Search

SQLite FTS5 with BM25 ranking searches OCR text and optional local Whisper audio transcripts, seeking the video player directly to the matching millisecond.

🔎

Native Finder & Spotlight Search

Writes deduplicated frame text into macOS Finder comments (kMDItemFinderComment), so typing any word from a video in Finder finds it immediately.

⚡

Apple Vision Neural Engine

Uses Apple's native VNRecognizeTextRequest via PyObjC for fast, accurate on-device text and bounding-box extraction with zero cloud latency.

🔒

1-Click Privacy Redactor

Automatically detects OpenAI/AWS/GitHub keys, Bearer tokens, and email addresses, applying Gaussian blur over their exact bounding boxes before you share.

🗜

VideoToolbox Compression

Compresses bloated macOS .mov captures with hardware-accelerated h264_videotoolbox, cutting file sizes by 80–90% while staying crisp.

📂

Zero-Touch Background Daemon

Runs silently via macOS LaunchAgent watching ~/Desktop and ~/Movies. Record with ⌘⇧5 and let FrameFind handle the rest.

Pipeline

How FrameFind works under the hood

01

Detect & Sample

Watchdog monitors your Desktop & Movies folders. When a capture finishes writing, FrameFind extracts keyframes on scene changes and periodic intervals.

02

Recognize & Rename

Apple Vision extracts text and bounding boxes. SmartNamer identifies the active app and primary heading, renames the file, and updates Spotlight metadata.

03

Search, Redact & Compress

Query anything in the PySide6 desktop app or CLI. Jump to highlighted matches, blur sensitive credentials in one click, or shrink multi-gigabyte recordings.

Quickstart

Up and running in 60 seconds

Requires macOS (Apple Silicon or Intel) and Python 3.10+.

git clone https://github.com/Rini020601/FrameFind.git
cd FrameFind
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# Launch the native PySide6 desktop app
python main.py

# Or use the CLI directly
python main.py index ~/Desktop
python main.py search "TypeError"
python main.py stats
# Install as a silent macOS LaunchAgent (auto-starts on login)
python daemon.py install

# Check service status
python daemon.py status

# Uninstall anytime
python daemon.py uninstall
